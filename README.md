# Nawaf AI

واجهة المساعد الشخصي لنواف، مبنية بـ React + Vite ومهيأة للنشر على Vercel.

## النسخة الحالية
- واجهة عربية RTL داكنة ومتجاوبة للجوال والكمبيوتر.
- مساحة Hero مخصصة للشخصية ثلاثية الأبعاد.
- نظام Living Mascot يبدّل حالة الشخصية تلقائيًا في أوقات عشوائية.
- تفاعل عند الضغط على الشخصية وردود فعل عشوائية.
- حالات أولية: لعب، بريك/أكل، مشاهدة، حماس/احتفال.
- محادثة تجريبية وبطاقات اختصارات للمشاريع والأفكار والبرمجة.

## التشغيل
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

> ملاحظة: نظام الشخصية مصمم ليتوسع لاحقًا بملابس وإضافات ومشاهد وحركات أكثر بدون تغيير هوية الشخصية الأساسية.
